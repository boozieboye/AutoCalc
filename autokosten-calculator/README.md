# Autokosten Calculator

Een eenvoudige Nederlandstalige website die berekent:

- brandstofkosten per maand;
- vaste en overige kosten;
- totale maandkosten;
- totale jaarkosten;
- kosten per kilometer.

## Lokaal openen

Open `index.html` in een browser.

## Bestanden

- `index.html`: inhoud en structuur;
- `style.css`: ontwerp en mobiele weergave;
- `script.js`: berekeningen, invoercontrole en lokale opslag.

## Online zetten

Deze website is statisch en kan rechtstreeks worden gehost via bijvoorbeeld:

- Cloudflare Pages;
- GitHub Pages;
- Netlify.

Er is geen database of backend nodig.
